# 投资政策书（IPS）· 草案 v0

> 本文是 [[07-行为风险与投资政策书]] 模板的填写草案。数字取自仓库现有研究结果（`output/research/`）。
> **`____` 和【确认】只能由本人填写**：能否承受、投入多少钱，代码和研究替你回答不了。
> 签字前本文不生效；签字后修改须走第 8 节的流程。

## 1. 目标

- 首要目标：**控回撤**。组合最大回撤目标 ≤ 20%（现实口径冻结期 2017–2024 为 17.8%）。
- 次要目标：长期收益不低于静态 60/40。
- **明确接受**：牛市里大幅跑输沪深300。现实口径 2015–2024 只有 4/10 年跑赢买入持有。

## 2. 规则（与回测、模拟盘 v2 同构）

| 项 | 规则 |
|---|---|
| 信号 | 沪深300 **价格指数**收盘价 vs 200 日简单均线；收盘 ≥ 均线 = 持有，< 均线 = 空仓 |
| 执行 | 信号日**次一交易日开盘**（或集合竞价）执行；不提前、不推迟、不分批 |
| 持有时仓位 | 股票 60% / 现金类 40% |
| 空仓时仓位 | 股票 0% / 现金类 100% |
| 再平衡 | 持有状态下，每年 1 月、7 月首个交易日开盘调回 60% |
| 股票工具 | 沪深300 ETF：____（建议 510300 或 510310，选一只固定不换） |
| 现金类工具 | ____（场内货基 / 国债逆回购 / 短债 ETF 选一种固定使用） |

## 3. 不允许的人工偏离

- 不因新闻、政策、"感觉要涨/要跌"提前或推迟执行信号。
- 空仓期间指数急涨（9·24 式）**不追**，等信号。
- 不在规则外加仓、减仓、换标的。
- 允许的例外（事先写死，其余一律不许）：
  1. 账户资金需求：____
  2. 券商 / ETF 停牌等无法交易的情况：顺延到下一个可交易时点

## 6. 复盘

- 频率：每季度一次。
- **只检查是否按规则执行**（信号日、成交日、成交价、仓位），**不看收益决定去留**。
- 记录：每次实际成交与模拟盘 v2 同日记录对比，偏差 > 0.5% 时写明原因。

## 7. 下线 / 暂停标准（任一触发 → 暂停新资金，回到研究流程，**不现场改参数**）

1. 前向最大回撤 > 回测最大回撤 × 1.5（即 > 26.7%）
2. 前向任意 12 个月翻转次数 > 19
3. 连续 3 个自然年收益跑输静态 60/40，**且**回撤也不比静态 60/40 小（滚动验证"回撤更小"一列失效）
4. 实盘与模拟盘 v2 同期收益偏差连续两个季度 > 2%（说明执行口径和回测不是同一个策略）

## 8. 修改规则的流程

- 新规则（换均线周期、加缓冲带、改仓位）必须：预注册 → 在 [[08-证伪档案与试验总账本]] 记一行 → 冻结期验证 → 模拟盘 ≥ 6 个月 → 才可替换。
- 不允许在亏损期间修改规则。
