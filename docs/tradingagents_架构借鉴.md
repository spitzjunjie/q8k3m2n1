# TradingAgents 架构借鉴笔记

> 背景：TradingAgents（美股多智能体 LLM 交易框架）不直接部署、不直接使用。
> 只取其"多智能体编排"思路，映射到 multi_strategy_trading。它的分析师信号是美股源（StockTwits/FRED/Reddit），对 A 股无效，不抄。

## TradingAgents 的 agent 分工

分析师团队（4 个）→ 研究员团队（多空辩论）→ 交易员 → 风控团队 → 组合经理（最终拍板）→ 模拟交易所

1. **分析师**：基本面 / 情绪 / 新闻 / 技术，各自产出信号
2. **研究员**：看多 vs 看空两个角色，对分析师结论做对抗式辩论
3. **交易员**：综合报告，决定买卖方向和仓位
4. **风控团队**：只评估波动/流动性/风险，有权否决交易员
5. **组合经理**：最终批准/否决，批准后下单到模拟交易所

## 映射到 multi_strategy_trading

| TradingAgents 环节 | 你现有的对应 | 结论 |
|---|---|---|
| 分析师（基本面/技术/情绪/新闻） | strategies/ 下 80+ 策略（factor/technical/sentiment/news/event 等） | ✅ 你已远超它，无需借 |
| 研究员（多空辩论） | strategy_discovery/market_analyzer（无显式对抗） | ⭐ 值得借 |
| 交易员 | core/execution.py + trading/simulator.py | ✅ 你已有 |
| 风控团队（独立否决） | core/costs.py + metrics.py（无独立否决环节） | ⭐ 值得借 |
| 组合经理（最终拍板） | 无独立聚合决策层 | ⭐ 值得借 |
| 数据源 | tushare / joinquant（A 股） | ✅ 你更对口 |

## 三条值得借鉴的设计（按价值排序）

1. **多空对抗辩论**：在 market_analyzer / discoverer 里，让"看多""看空"两个 LLM 角色对同一批信号互相挑刺，辩论后再交决策。你现有策略多是单边信号，加这一层能治"过度自信"。
2. **风控否决闸**：交易员出决策后，独立的"风控"角色只评估风险、有一票否决权，而不是把风险杂糅进每个策略里。你已有 costs/metrics，缺的是"独立否决"这一步。
3. **组合经理拍板**：把"最终买不买、买多少"抽成独立决策层，聚合下面所有信号 + 风控意见，而不是让单个策略各自下注。

## 不抄的部分

- 它的分析师信号是美股源，对 A 股无效；你的 tushare/joinquant + 80 策略已经更强。
- 它的"数据→信号"层很薄；你已有成熟的因子/事件/资金流/龙虎榜体系。

## 落地建议（如果要动手）

优先级：先做"多空对抗"（改动最小、收益最大），在 strategy_discovery 的 LLM 分析流程里加一个看多/看空辩论回合，输出"共识 + 分歧点"，再喂给选股决策。
