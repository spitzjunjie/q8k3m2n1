## 研究脚本运行方式（本地无需运行）

在 GitHub Actions 手动触发「现实口径研究（手动）」工作流即可，结果自动提交到 `output/research/`。
等价命令：

```bash
# 1. 现实口径重跑冻结期：真实利率 + 全收益 + 单边 10bp + 次日执行
python asset_allocation_backtest.py --real-bond --total-return --cost-bps 10 --signal-lag 1 --oos-split 20161231
python asset_allocation_backtest.py --real-bond --total-return --cost-bps 10 --signal-lag 1 --rolling
# 1b. 2025 起新数据：滚动延伸到 2026（对比静态 60/40）+ 一次性新样本外
python asset_allocation_backtest.py --real-bond --total-return --cost-bps 10 --signal-lag 1 --end 20260930 --rolling --rolling-last-year 2026
python asset_allocation_backtest.py --real-bond --total-return --cost-bps 10 --signal-lag 1 --end 20260930 --holdout-start 20250101
# 2. MA200 风险画像 → 回填 [[07-行为风险与投资政策书]] 痛苦表、[[06-A股失效环境案例库]] 事件状态
python ma200_risk_profile.py
```

模拟盘 v2 不需要手动跑：CI 下一次运行会自动归档 v1 状态并按新口径从 2026-08-18 起回放。
