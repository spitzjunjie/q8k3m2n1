# 行为风险与投资政策书（IPS）

## 证据

- Morningstar《Mind the Gap 2025》：截至 2024 年末的 10 年，美国基金投资者的资金加权收益 7.0%/年，
  基金本身 8.2%/年，差 1.2 个百分点（约 15% 的收益）。配置型基金差距约 0，行业主题基金最大（-1.5%）。
  "交易越多，赚得越少"。
- **反方**：Financial Analysts Journal 2026 年的一篇文章认为这个 15% 被高估，
  "糟糕的择时并没有让投资者损失 15%"。→ 差距的大小有争议，**方向**（追涨杀跌有代价）没有争议。
- 对本项目：择时策略本身就是"规则化的择时"，最大的风险是**在规则之上再叠一层人工择时**。
  最典型场景：空仓期碰上 9·24 式急涨 → 手动追进 → 随后均线信号又翻空。

## 投资政策书（IPS）模板 · 待填

```
1. 目标：控回撤优先，可接受跑输牛市。
2. 规则：60/40 + MA200（沪深300 收盘 vs 200 日均线，次日开盘执行），1/7 月首日再平衡。
3. 允许人工偏离的情形：无。（若有，必须事先写在此处，例：账户资金需求。）
4. 资金：投入金额上限 ____；该资金 __ 年内不动用。
5. 复盘频率：每季度一次，只看是否按规则执行，不看收益。
6. 修改规则的流程：新规则须走预注册 + 冻结期验证，至少 6 个月模拟盘后才可替换。
```

## 下线 / 失效标准（事先写死）

> 以下为建议值，确认后签字日期写在这里：________

- 前向（模拟盘或实盘）最大回撤 > 回测最大回撤 × 1.5
- 前向 12 个月内翻转次数 > 历史单年最大翻转次数
- 连续 3 年跑输 60/40 静态组合且回撤没有更小（策略卖点失效）

触发任一条 → 暂停新资金投入，回到研究流程，**而不是**现场改参数。
