# 投资政策书（IPS）· 草案 v1：静态 60/40

> 2026-10-03 决定：实盘主线采用**静态 60/40 半年再平衡**，不做 MA200 择时。
> 依据：现实口径下 MA200 收益与夏普均略低于静态 60/40（滚动 2015–2026/09 每年约少 0.7 个百分点，
> 2025-01 ~ 2026-09 新样本外也一样），只在熊市里回撤更小，见 [[01-回测与实盘口径对照]]。
> MA200 模拟盘继续运行，仅作对照，不作为交易依据。
>
> **`____` 和【确认】只能由本人填写**。签字前本文不生效；签字后修改须走第 8 节的流程。
> （v0 为 MA200 版本，见 git 历史。）

## 1. 目标

- 长期获取 A 股大盘股的大部分收益，同时把波动压到满仓的约六成。
- **明确接受**：
  - 熊市中组合会有较大回撤（历史最坏约 49%，见第 5 节），**不会**因此卖出。
  - 牛市中跑输满仓沪深300。

## 2. 规则

| 项 | 规则 |
|---|---|
| 目标仓位 | 股票 60% / 现金类 40%，**始终如此**，不看任何信号 |
| 再平衡 | 每年 1 月、7 月首个交易日，调回 60/40 |
| 执行 | 再平衡日开盘（或集合竞价）一次性完成；不提前、不推迟、不分批 |
| 股票工具 | 沪深300 ETF：____（建议 510300 或 510310，选一只固定不换） |
| 现金类工具 | ____（场内货基 / 国债逆回购 / 短债 ETF 选一种固定使用） |
| 新增资金 | 只在再平衡日投入，按 60/40 分配 |

下一次再平衡日：**2027 年 1 月首个交易日**。

## 3. 不允许的人工偏离

- 不因新闻、政策、"感觉要涨/要跌"在两次再平衡之间买卖。
- 大跌时不"抄底加仓"，大涨时不"止盈减仓"——这两件事由再平衡自动完成。
- 不换标的，不加新品种（核心-卫星等方案须走第 8 节流程）。
- 允许的例外（事先写死，其余一律不许）：
  1. 账户资金需求：____
  2. 券商 / ETF 停牌等无法交易：顺延到下一个可交易时点

## 5. 预期痛苦（签字前逐条回答"能否承受"）

数字为全收益指数 + SHIBOR 真实利率 + 单边 10bp 成本的回测，原始输出在 `output/research/`。

| 情形 | 历史值 | 能承受吗【确认】 |
|---|---|---|
| 组合最大回撤（2006–2016，含 2008） | **48.6%**：10 万元一度只剩约 5.1 万 | |
| 组合最大回撤（2017–2024） | 25.5% | |
| 单年最大回撤（2015–2026/09 逐年） | 28.3%（2015 股灾） | |
| 最差年份收益 | -14.1%（2018）、-11.3%（2022） | |
| 跑输满仓沪深300 | 牛市年常见：2019 年 +25.3% vs +41.1%，2025 年 +15.2% vs +24.6% | |
| 2017–2024 累计收益 | +35.9%（年化约 4.1%），8 年里大部分收益来自少数几年 | |

**读法**：静态 60/40 没有择时的打脸和踏空，但**熊市里要硬扛**。2008 年式的行情会让组合腰斩，
而规则要求此时继续持有、并在再平衡日**买入**股票把仓位补回 60%。这是本方案唯一的、也是最大的考验。

## 6. 复盘

- 频率：每次再平衡日（每年 2 次）。
- **只检查是否按规则执行**（日期、成交价、调整后是否 60/40），**不看收益决定去留**。
- 记录：实际成交与模拟盘（`output/static6040_paper_state.json`）同日记录对比，偏差 > 0.5% 时写明原因。

## 7. 暂停标准（触发 → 暂停新资金投入并复盘，**不卖出已有仓位**，不现场改规则）

1. 组合回撤 > 50%（超过历史最坏）
2. 实盘与模拟盘同期收益偏差连续两次复盘 > 2%（说明执行和规则不一致）
3. 本人资金状况变化，第 4 节的"不动用期限"无法保证

## 8. 修改规则的流程

- 新规则（改比例、加择时、换品种）必须：预注册 → 在 [[08-证伪档案与试验总账本]] 记一行 → 冻结期验证 → 模拟盘 ≥ 6 个月 → 才可替换。
- 不允许在亏损期间修改规则。
