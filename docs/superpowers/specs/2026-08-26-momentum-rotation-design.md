# 三指数动量轮动策略 · 设计文档

> 日期：2026-08-26
> 状态：设计已经用户逐节确认，待写实现计划
> 背景与动机：选股 alpha 已被系统性证伪（77 策略 + 朴素因子 + 经典因子 + PEAD 全部置换检验不显著），
> 主线转向指数层面（60/40 + MA200 已过样本外验证）。本策略是指数方向的第二个成员：
> MA200 管「股 vs 现金」，轮动管「持有哪类股」，二者互补且验证协议同构、结论可互相印证。
> 纪律来源：《不显著怎么办.txt》与本项目 8 月研究结论——先假设后回测、参数写死、冻结样本外、0 是合法结论。

## 一、一句话

每月末比较沪深300 / 中证500 / 红利低波三个指数的 N 个月涨幅，下月持有最强的那个；
连最强的都跑不赢现金时，下月全现金（双动量）。

## 二、策略规则（写死，不调参）

- **标的**：
  - 000300.SH（沪深300）
  - 000905.SH（中证500）
  - H30269.CSI（中证红利低波动指数；实盘对应 512890 ETF）
  - 现金：SHIBOR 1w 真实日利率（复用 `--real-bond` 的数据与逻辑；SHIBOR 自 2007-01 发布，
    2006 年缺失期按现有逻辑的固定 3.5% 兜底）
- **信号**（每月最后一个交易日收盘计算）：
  - **相对动量**：三个指数「当月月末收盘 / N 个自然月前月末收盘 − 1」，最高者胜出
  - **绝对动量**：胜出者收益 ≤ 现金同期（N 个月）收益 → 下月全现金
- **执行**：次月首个交易日按**开盘价**调仓（收盘判断、次日执行，与 MA200 规则一致）；月内不动作
- **权重**：选中资产 100%（或现金 100%）
- **成本**：单边 0.1%（佣金+滑点保守值），换仓时卖出、买入各计一次
- **N（动量回看期）**：{3, 6, 12} 月，研发期比较后选定并写死，此后永不更改

## 三、验证协议（预注册）

- **数据**：Tushare `index_daily`（已实测：000300/000905 自 2005-01-04、H30269.CSI 自 2005-12-30 可得，
  2150 积分够用）+ `shibor`；本地缓存复用 `output/index_cache.json` 机制。
- **切分**：
  - 研发期 2006-01-01 ~ 2016-12-31：仅用于比较 {3, 6, 12} 选定 N
  - 冻结期 2017-01-01 ~ 2024-12-31：全部最终数字只从这里出，**只跑一次**，跑完不再改任何参数
- **冻结期基准**：
  1. 等权买入持有三资产（主对照，月度再平衡到等权；再平衡换手同样计 0.1% 单边成本）
  2. 各单资产买入持有（3 条；几乎无换手，不计成本）
  3. 现有 60/40 + MA200 趋势过滤（与主线互相印证）
- **置换检验**（1000 次，冻结期）：
  - **主检验 N2（风险匹配）**：策略处于现金时，随机组同日也现金；策略持有时，随机组当月等概率
    持有三资产之一 → 单独检验「选资产是否有信息」
  - 参考 N1（满仓随机）：随机组永远等概率三选一 → 检验「择资产+择时」整体
- **及格线（预注册，三条全过才采纳）**：
  1. 冻结期总收益 ≥ 等权买入持有
  2. 冻结期最大回撤 ≤ 等权买入持有的 2/3
  3. N2 置换检验 p < 0.05
- **多重检验披露**：研发期 3 选 1 属 3 次检验，须写进最终报告；冻结期检验只跑一次。

## 四、工程实现

- **新文件**：`momentum_rotation_backtest.py`
  - `import` `asset_allocation_backtest.py` 的数据层（`load_prices`、`index_cache.json`、SHIBOR 因子）
    与绩效汇总函数——该脚本有 `__main__` 保护、可安全导入，零重复
  - 轮动结果写独立 `output/momentum_rotation_results.json`，不碰现有产物
- **核心为纯函数**：价格序列 → 每月持仓序列 → 权益曲线；信号、成本、执行时点各自独立可测，
  置换检验直接复用同一回测函数（只替换持仓来源）
- **单元测试**：`tests/test_momentum_rotation.py`——动量计算、绝对动量现金切换、成本扣减、
  月末信号/次月开盘执行的时点正确性；进 pytest 冒烟门禁
- **CI**：研究阶段不加定时任务，手动运行；若冻结期三条件全过并决定采纳，
  再按 MA200 模式加每日模拟盘 + CI 记账（下一步，不在本设计范围）

## 五、局限与风险（预披露）

1. **红利低波 2019 年前不可投**：512890 上市于 2019-01，此前用指数代理；2019 后可切 ETF 复核一致性
2. **A 股动量效应弱、短期反转强**：策略可能直接不及格；**0 是合法结论**，预注册及格线即为诚实面对它
3. **选择偏差**：研发期 3 选 1 有轻度选择偏差，置换检验仅部分对冲
4. **月频固有代价**：风格急切换月（如 2014 底）会明显回撤
5. **结论边界**：仅对 2006–2024 A 股成立，不构成未来承诺；采纳后实盘前仍需 3–6 个月模拟盘前向验证
